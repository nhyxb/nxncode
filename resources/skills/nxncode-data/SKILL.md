# 数据与报告

确认输入文件、业务问题和交付格式，先检查字段、编码、单位、日期范围、缺失值与重复记录。只读取任务需要的已授权路径，原文件默认保留；使用本机已有工具，不默认上传到在线分析服务。

在计算前明确统计口径：分母、分组、时间粒度、去重规则和币种。缺失、零值与异常值分别处理；关联数据时检查键的唯一性和未匹配记录。避免把过滤后的小样本误当总体。

用可重复的脚本或查询生成分析，交叉核对关键总量和抽样明细。图表展示真实数据和清晰单位，日期排序与数值轴合理；不隐藏会改变结论的缺失信息。

按用户需要输出真实 CSV、JSON、HTML 或项目支持的报告文件，记录输入来源与计算口径。交互图表使用 nxncode 的 show_widget，文件用 show_in_panel 展示；若相关工具不可用，交付实际文件路径，不声称已经打开。导出可能含不可信文本的电子表格数据时处理公式前缀，避免把文本作为公式执行。
