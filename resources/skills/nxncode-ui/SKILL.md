# 界面改进

检查已有组件、样式、真实文案及设计约束，区分局部修正与整体重设计。用户给出的配色、截图、视频和交互要求优先；局部改进不替换整个视觉体系，也不添加虚构用户数据。

先处理层级、间距、内容溢出与主要操作的可发现性，再调整装饰。复用项目现有图标、字体和组件；表单保留标签、键盘焦点、错误恢复以及提交状态。交互成功必须对应实际数据更新。

动效表达用户操作与状态连续性，支持中途反向、重复操作和减少动态偏好。持续效果在窗口隐藏或离屏时停止；一次性开场按真实状态变化触发，不能把组件重建当作新的用户操作。

在实际运行的界面检查结果，覆盖相关屏幕宽度、真实内容和一个关键边界。网页操作使用 nxncode 内置可见浏览器工具，与用户查看同一页面，不另起另一套浏览器。核对实际鼠标或键盘路径，不用不同输入方式的测试代替用户报告的故障。
